- ¿Qué significa DAO?

Significa Data Access Object (Objeto de Acceso a Datos).


- ¿Cuál es su responsabilidad principal?

Aislar y encapsular todas las operaciones de acceso y manipulación de datos en una fuente de almacenamiento


- ¿Qué relación tiene DAO con una base de datos?

Es la capa intermediaria entre la base de datos y el resto del programa. Si cambiamos de base de datos relacional a NoSQL, solo modificamos el DAO.


- ¿Qué operaciones aparecen habitualmente en un DAO?

selectAll, selectById, insert, update y delete.
